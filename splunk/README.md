# Splunk Queries

This folder contains Splunk SPL queries used for threat hunting and detection engineering.

The queries in this directory are designed to detect suspicious behaviors associated with attacker techniques and are often derived from Sigma rules, threat hunts, or security research.

Focus areas include:

- Suspicious process execution
- Living-off-the-Land (LOLBins) abuse
- Credential access activity
- Persistence mechanisms
- Lateral movement techniques

Where possible, queries are mapped to MITRE ATT&CK techniques and include notes on tuning, false positives, and investigative context.

These queries are intended to support both proactive threat hunting and operational detection use cases within Splunk environments.
