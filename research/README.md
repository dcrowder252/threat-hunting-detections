# Research

This folder contains cybersecurity research and technical analysis related to threat detection, adversary tradecraft, and defensive security techniques.

Topics may include:

- Analysis of public threat reports
- Detection engineering methodologies
- Breakdown of attacker techniques
- Command and control (C2) infrastructure analysis
- Malware behavior analysis
- Detection opportunities mapped to MITRE ATT&CK

The goal of this research is to translate real-world adversary behavior into actionable detection strategies that can be implemented in security monitoring platforms.
