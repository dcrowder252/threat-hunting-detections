# CrowdStrike Queries

This folder contains threat hunting and detection queries designed for the CrowdStrike platform, including Falcon LogScale and Next-Gen SIEM.

The queries focus on identifying suspicious behavior across endpoint telemetry, including:

- Suspicious process execution
- Living-off-the-Land (LOLBins) abuse
- Credential access techniques
- Persistence mechanisms
- Lateral movement activity

Many of these queries are derived from Sigma rules or threat hunting investigations contained within this repository.

Where applicable, queries are mapped to MITRE ATT&CK techniques and include notes on tuning and investigation context.
